# Local NPC Chat RPG（ローカルNPCチャット）

**v0.9.0-build.001** — 実験用プロトタイプ

公開URL: https://egoaid.github.io/Local-NPC-Chat/

のどかな町「こもれび町」の住人4人と、自由におしゃべりできるWebアプリです。会話を考えるAIは、**あなたのブラウザの中だけ**で動きます。

## 住人について
最初は住人がいません。「＋ 住人を追加」で、名前・年齢・性別・職業・性格・話し方などを入力して、自分だけの住人を作れます（最大12人）。名前や設定は、あとから「編集」でいつでも変えられます。

「サンプル住人」から、次の4人を追加することもできます（追加後は自由に編集できます）。

## はじめかた
1. 対応ブラウザでこのページを開きます。
2. 画面の一番下にある「ローカルAIモデル」で、「ダウンロードして読み込む」を押します（初回のみ）。
3. 住人を追加（または選択）して、下の入力欄から話しかけます。Enterで送信（スマホでは送信ボタン）。
4. 「停止」で返事の生成を止められます。「新しい会話」「会話を消去」で会話をやり直せます。

## ローカルAIのしくみ
会話の返事は、小さな言語モデル（LiquidAI **LFM2.5**）があなたの端末のGPU（WebGPU）で作ります。モデルは画面上で切り替えられます。サーバーやAPIキーは使いません。**会話内容は外部に送信されません。**
- **350M**（約290MB）: 軽くて速い。日本語はやや不自然なことがあります。
- **1.2B-JP**（約744MB）: 日本語向けの大きめのモデル。メモリに余裕があり、WebGPUのshader-f16に対応した端末向け。

GPUメモリを無駄に使わないよう、同時に読み込まれるモデルは1つだけです。切り替えると先に前のモデルを解放します。「GPUメモリを解放」ボタンで手動解放もでき、しばらくタブを開いたまま放置した場合も自動で解放されます（戻ると自動で再読み込み）。

小さなモデルなので、ときどき不自然な返事や、勘違い、同じ言い回しの繰り返しが起きます。それも実験の一部です。

## 世界と住人の設定
画面下の「世界と住人の設定」から、次を設定できます。
- **世界の時間**：端末の時計に合わせて、朝・昼・夕方・夜・深夜の雰囲気で会話します（朝5時〜／昼11時〜／夕方16時〜／夜19時〜／深夜0時〜）。手動で時間帯を固定することもできます。
- **この世界の設定**（500字まで）：世界観を文章で入力すると、住人が事実として会話に反映します。
- **住人ごとの追加設定**（300字まで）：選んでいる住人にだけ効く設定です。
- **返答の長さ**：短め／ふつう／長め。返事が途中で切れた場合は、最後に言い終えた文までに整えます。
- 設定はこの端末のブラウザに自動保存されます。「設定を書き出す」でJSONファイルとして保存でき、「設定を読み込む」で別の端末などに移せます（会話履歴とAIモデルは含まれません）。
- 設定が長いほど、返事が始まるまでの時間がわずかに長くなることがあります。

## 住人の作り方のコツ
- 「セリフ例」を1〜3行入れると、口調が安定します。
- 設定の合計が長いほど、返事が始まるまでの時間が長くなります（編集画面に合計の目安が出ます。約700字までがおすすめ）。
- 「追加設定」に書いたことは、住人が事実として会話に反映します。
- 住人を書き出して（JSON）、別の端末や友だちと共有できます。読み込むときは中身を検証します。

## データとバックアップ
- 住人・会話・設定は、この端末のブラウザ内（IndexedDB）に保存されます。外部には送信されません。
- 「データとバックアップ」から、住人・世界観・あなたの設定を**バックアップ**として書き出し、読み込めます。「会話も含めて書き出す」を選ぶと、会話履歴と記憶も入ります。AIモデルは含まれません。
- 「保存領域を消えにくくする」を押すと、ブラウザがデータを自動で消しにくくなります（許可されない場合があります）。
- ブラウザのデータ削除や端末の初期化で消えることがあるので、大事な住人は定期的にバックアップしてください。

## あなた（プレイヤー）の設定
「世界と住人の設定」で、あなたの名前・プロフィール・性格を入力できます。
- 住人は、**初対面ではあなたの名前もプロフィールも知りません**。名前では呼ばず、決めつけもしません。
- 会話の中であなたが名前を名乗ると、その住人は名前・プロフィール・性格を知った状態になり、名前を**ときどき**（毎回ではなく）呼ぶようになります。
- 知っているかどうかは住人ごとに別です。住人ごとのチェックで手動でも切り替えられます。「会話を消去」「新しい会話」「この住人の記憶を消す」で、初対面に戻ります。
- 名前を入力していない場合は、プロフィールと性格だけが、知った状態の住人に伝わります。

## みんなで遊ぶ（住人同士の会話）
「みんなで遊ぶ」から、住人同士の会話を観ることができます。住人を2〜4人選んで、モードを選び、「開始」を押します。
- **物語づくり**：タイトルやテーマ（例：森の館で起きたサスペンスストーリー）を入れると、住人たちが1人ずつ即興でお話を作っていきます。話は「導入→事件→展開→意外な事実→クライマックス→結末」と進み、最後は自然に締めくくられます。途中で「展開の指示」（例：ここで停電が起きる）を入れると、次の発言から取り入れます。終わったら「テキストで保存」できます。
- **しりとり**：住人同士で、しりとりをします。「あなたも参加する」をオンにすると、ひらがなで答えて一緒に遊べます。「ん」で終わる言葉や、使った言葉を言うと負けです。判定はプログラムが行うので、AIの勘違いで勝敗が狂うことはありません（濁点は同じ音として扱います：「ご」の次は「こ」でもOK）。
- 「自動で進める」か「1発言ずつ進める」を選べます。読み上げをオンにしていれば、その住人の声で読み上げます。
- 動作を軽くするため、話すのは1回に1人だけで、発言は短く、タブが見えないときは自動で一時停止します。普通のチャットを送ると、住人同士の会話は一時停止します。

## 日付・季節と、住人から話しかけてくる機能
- 住人は、この端末の**日付・曜日・季節**を知っています。「今日は何日？」「何曜日？」「今何時？」と聞くと、実際の日付・時刻で答えます。季節（春夏秋冬）や、元日・クリスマスなどの行事に合わせた話題でも話します。「世界とプレイヤーの設定」で、日付を固定することもできます。
- 住人が自分から話しかけてくる機能があります。AIモデルの準備ができると、**1人だけ**が話しかけます。その後は、時間をおいて1人ずつ話しかけます。話しかける内容は短い一言です。
- 話しかけるたびにGPUを使うため、「世界とプレイヤーの設定」でオン/オフと間隔を変えられます。重いときはオフにしてください。
- あなたが入力を始めると、話しかけの生成は中断されます。返事をしないまま3回話しかけたあとは、あなたが何か送るまで止まります。別の住人が話しかけたときは、その住人のカードに「💬新着」が出ます。

## 動作が重いとき
画面下の「ローカルAIモデル」に、次の設定があります。動作の目安は同じ場所の「診断」で見られます（返事の開始までの時間、1秒あたりの生成量など）。コピーして不具合の報告にも使えます。
- **別スレッドで推論する**（既定でオン）：AIの計算を別のスレッドで行い、画面が固まりにくくします。使えない環境では自動で通常の方式に切り替わります。
- **軽量モード**：会話の履歴を短くして、AIの1回あたりの負荷を下げます（その分、少し前の話を忘れやすくなります）。
- それでも重いときは、350Mモデルに切り替えるか、他のタブやアプリを閉じてください。

## 会話の記憶
- 住人は、直近の会話（約1500字ぶん）をそのまま覚えています。
- それより古い会話は、AIが短いメモ（300字まで）にまとめて覚えます。メモづくりは返事のあとにこっそり行われ、次のメッセージを送ると中断されます。
- 「世界と住人の設定」で、記憶のオン/オフと、住人が覚えている内容の確認ができます。メモが間違っているときは「この住人の記憶を消す」で消せます。
- 小さなAIがまとめるので、メモが不正確になることがあります。記憶は会話履歴とともにこの端末だけに保存されます。

## 初回ダウンロードとオフライン
- 初回は選んだモデル（350Mは約290MB、1.2B-JPは約744MB）をダウンロードし、ブラウザ内に保存します。Wi‑Fi接続をおすすめします。保存済みのモデルは「保存データを削除」で個別に消せます。
- 2回目以降は保存済みのモデルを使います。アプリ本体も保存されるので、一度読み込んだ後は通信なしでも会話できます（ブラウザが保存データを自動削除した場合を除く）。
- アプリが更新されても、モデルは再ダウンロードされません。新バージョンがあると通知が出ます（自動では再読み込みしません）。

## 対応ブラウザ
WebGPUが使える最近のブラウザ（例：PCのChrome / Edge、WebGPU対応のAndroid・iOS・macOSブラウザ）。非対応の場合は、画面にその旨が表示されます。端末のメモリが少ないと動かないことがあります。

## 音声読み上げ
ブラウザの音声合成機能で返事を読み上げます（オン／オフ、速度、声を選べます）。日本語・英語の声を端末から検出し、男性キャラには男性らしい声、女性キャラには女性らしい声を、見つかる範囲で選びます。
**Microsoft Online Natural音声**は、Microsoft Edgeなど、その声が使える環境でのみ利用でき、使える場合に優先されます。無い環境では端末標準の声になります。画面には実際に選ばれた声の名前が表示されます。音声ファイルは同梱していません。

## プライバシー
会話履歴と設定は、この端末のブラウザ内にのみ保存されます。「データ管理」から会話の削除やアプリのリセットができます。
