**v0.3.0-build.001** — 実験用プロトタイプ

公開URL: https://egoaid.github.io/Local-NPC-Chat/

のどかな町「こもれび町」の住人4人と、自由におしゃべりできるWebアプリです。会話を考えるAIは、**あなたのブラウザの中だけ**で動きます。

## はじめかた
1. 対応ブラウザでこのページを開きます。
2. 「モデルをダウンロードして開始」を押します（初回のみ）。
3. 住人を選んで、下の入力欄から話しかけます。Enterで送信（スマホでは送信ボタン）。
4. 「停止」で返事の生成を止められます。「新しい会話」「会話を消去」で会話をやり直せます。

## ローカルAIのしくみ
会話の返事は、小さな言語モデル（LiquidAI **LFM2.5**）があなたの端末のGPU（WebGPU）で作ります。モデルは画面上で切り替えられます。サーバーやAPIキーは使いません。**会話内容は外部に送信されません。**
- **350M**（約290MB）: 軽くて速い。日本語はやや不自然なことがあります。
- **1.2B-JP**（約744MB）: 日本語向けの大きめのモデル。メモリに余裕があり、WebGPUのshader-f16に対応した端末向け。

GPUメモリを無駄に使わないよう、同時に読み込まれるモデルは1つだけです。切り替えると先に前のモデルを解放します。「GPUメモリを解放」ボタンで手動解放もでき、しばらくタブを開いたまま放置した場合も自動で解放されます（戻ると自動で再読み込み）。

小さなモデルなので、ときどき不自然な返事や、勘違い、同じ言い回しの繰り返しが起きます。それも実験の一部です。

## 世界と住人の設定
画面下の「世界と住人の設定」から、次を設定できます。
- **世界の時間**：端末の時計に合わせて、朝・昼・夕方・夜・深夜の雰囲気で会話します（朝5時〜／昼11時〜／夕方16時〜／夜19時〜／深夜0時〜）。手動で時間帯を固定することもできます。
- **この世界の設定**（500字まで）：世界観を文章で入力すると、住人が事実として会話に反映します。
- **住人ごとの追加設定**（300字まで）：選んでいる住人にだけ効く設定です。
- **返答の長さ**：短め／ふつう／長め。返事が途中で切れた場合は、最後に言い終えた文までに整えます。
- 設定はこの端末のブラウザに自動保存されます。「設定を書き出す」でJSONファイルとして保存でき、「設定を読み込む」で別の端末などに移せます（会話履歴とAIモデルは含まれません）。
- 設定が長いほど、返事が始まるまでの時間がわずかに長くなることがあります。

## 初回ダウンロードとオフライン
- 初回は選んだモデル（350Mは約290MB、1.2B-JPは約744MB）をダウンロードし、ブラウザ内に保存します。Wi‑Fi接続をおすすめします。保存済みのモデルは「保存データを削除」で個別に消せます。
- 2回目以降は保存済みのモデルを使います。アプリ本体も保存されるので、一度読み込んだ後は通信なしでも会話できます（ブラウザが保存データを自動削除した場合を除く）。
- アプリが更新されても、モデルは再ダウンロードされません。新バージョンがあると通知が出ます（自動では再読み込みしません）。

## 対応ブラウザ
WebGPUが使える最近のブラウザ（例：PCのChrome / Edge、WebGPU対応のAndroid・iOS・macOSブラウザ）。非対応の場合は、画面にその旨が表示されます。端末のメモリが少ないと動かないことがあります。

## 音声読み上げ
ブラウザの音声合成機能で返事を読み上げます（オン／オフ、速度、声を選べます）。日本語・英語の声を端末から検出し、男性キャラには男性らしい声、女性キャラには女性らしい声を、見つかる範囲で選びます。
**Microsoft Online Natural音声**は、Microsoft Edgeなど、その声が使える環境でのみ利用でき、使える場合に優先されます。無い環境では端末標準の声になります。画面には実際に選ばれた声の名前が表示されます。音声ファイルは同梱していません。

## プライバシー
会話履歴と設定は、この端末のブラウザ内にのみ保存されます。「データ管理」から会話の削除やアプリのリセットができます。
