「＋ 住人を追加」で、名前や性格を決めて最初の住人を作りましょう。サンプル住人（4人）を追加することもできます。

AIモデルが未読み込みです。画面下の「ローカルAIモデル」から読み込んでください。 モデルの設定へ
音声の設定

Microsoft Online Natural音声は、対応するEdge等の環境にある場合のみ優先して使われます。無い場合は標準の声で読み上げます。

みんなで遊ぶ（住人同士の会話：物語づくり・しりとり）
参加する住人（2〜4人）

軽く動かすための工夫：話すのは1回に1人だけ、1回の発言は短く（物語は60字ほど、しりとりは言葉だけ）、ルールの判定はAIではなくプログラムが行います。物語では直近の流れだけを読み、しりとりでは使った言葉の一覧だけを渡します。タブが見えないときは自動で一時停止し、あなたが普通のチャットを送ると生成は中断されます。

世界とプレイヤーの設定（時間・世界観・あなたの設定・返答の長さ・記憶）

住人は、日付・曜日・季節（春夏秋冬）を知っていて、「今日は何日？」に答えます。季節に合わせた話題でも話します。

住人から話しかけてくる

AIモデルの準備ができると、住人が1人だけ話しかけます。その後は時間をおいて、1人ずつ話しかけます。話しかけるたびにGPUを使うので、重いときはオフにしてください。入力を始めると中断され、返事をしないまま3回話しかけたあとは止まります。

あなた（プレイヤー）の設定
0 / 300
0 / 300

住人は、初対面ではあなたの名前もプロフィールも知りません。会話の中であなたが名前を名乗ると、その住人は知った状態になり、名前を時々呼ぶようになります（毎回は呼びません）。

0 / 500

入力した設定は、この端末のブラウザに自動保存され、住人は事実として会話に反映します。設定が長いほど、返事が始まるまでの時間がわずかに長くなることがあります（特に1.2B-JP）。

データとバックアップ

バックアップには、住人・世界観・あなたの設定・時間/返答の長さ/記憶の設定が入ります。「会話も含めて書き出す」を選ぶと、会話履歴と記憶も入ります。AIモデルは含まれません。
